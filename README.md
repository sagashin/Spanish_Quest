# Vamos! Quest 🇪🇸⚽

13歳の日本の少年が、来年のスペイン渡航に向けてゼロから楽しくスペイン語を学べるゲーミフィケーション型Webアプリ。
教科書的な文法暗記ではなく、現地でのリアルなシチュエーション（挨拶、食事・買い物、サッカーやスポーツでの同年代との交流、移動）で使えるフレーズをパズルや音声で直感的に身につけ、学習履歴を蓄積・復習できます。

## 🌟 主な機能
- **ホーム＆達成度ダッシュボード**: レベル、XP、ストリーク（連続日数）、渡航準備度（称号システム）、SRS今日復習アラート
- **クエスト学習モード**: チャンク並び替えパズル、4択リスニング、Web Speech APIスピーキング挑戦
- **スマート復習コレクション**: トレカ風図鑑、忘却曲線（SRS）間隔反復復習
- **AIロールプレイ**: 現地でのリアルな3ターン対話シミュレーション（音声入力対応）
- **データ管理**: LocalStorage永続化、JSONエクスポート／インポートバックアップ

## 🚀 デプロイ
静的フロントエンド構成のため、Vercel、GitHub Pages、Cloudflare Pages等にそのままデプロイ可能です。
`index.html` がルートに配置されています。
